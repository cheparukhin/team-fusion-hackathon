# ESMFold sensitivity feasibility — not executed

On 20 September 2026 we reviewed a possible six-sequence, 118–600-aa, MSA-free cross-engine sensitivity analysis. No ESMFold installation, weight download, sequence submission, or inference was performed. The active Boltz2 pipeline remains the executed structure method; ESMFold is a possible follow-up, not a result.

The official [facebook/esmfold_v1 repository](https://huggingface.co/facebook/esmfold_v1/tree/75a3841ee059df2bf4d56688166c8fb459ddd97a) has revision `75a3841ee059df2bf4d56688166c8fb459ddd97a`, an 8.44-GB `pytorch_model.bin`, no safetensors artifact, and MIT model-card licensing. The [Transformers 4.57.3 implementation](https://github.com/huggingface/transformers/blob/v4.57.3/src/transformers/models/esm/modeling_esmfold.py) imports bundled OpenFold utilities; these use Apache 2.0 licensing. This route avoids building the separate native OpenFold package. It supports local sequence-only inference and attention chunking without an external MSA database or sequence API submission.

[Transformers 4.57.3 package requirements](https://github.com/huggingface/transformers/blob/v4.57.3/setup.py) include Python >=3.9, PyTorch >=2.2, Hugging Face Hub >=0.34,<1.0, tokenizers >=0.22,<=0.23, safetensors >=0.4.3 and NumPy. The folding code imports SciPy for initialization. Accelerate may be used for memory-efficient loading. The current unpinned Hugging Face protein-folding notebook has moved to ESMFold2, so it should not be treated as a version-pinned ESMFold-v1 recipe.

The compute worker's read-only check of the project-owned A100 80-GB environment found PyTorch 2.6.0+cu126, no Transformers/Accelerate/fair-esm installation, and no ESM weights in the checked Hugging Face or Torch caches. Serial 118–600-aa inference with chunking appears technically feasible on that GPU, but neither peak memory nor runtime was measured. Downloading 8.44 GB alone requires approximately 28 MB/s for five minutes or 70 MB/s for two minutes. A ten-minute cold setup therefore cannot be promised.

The coordinator deferred this additional environment and download to preserve the bounded, consistent Boltz2 campaign. Any future run must pin its environment, weights and confidence conventions; validate exact output sequence/coordinates; and keep its confidence and structural clustering separate by prediction protocol. Cross-engine agreement would remain a model sensitivity result, not evidence of translation or experimental structure.
