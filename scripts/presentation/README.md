# Editable presentation authoring

The gallery is a twelve-slide, workflow-first presentation of the reviewed frozen chRNA results. `build_gallery.py` writes editable native PowerPoint text/shapes (including exon diagrams and charts), plus shared-source SVG/PNG/PDF figures. The actual molecular renderings are embedded images from the structure worker; their underlying SVGs and molecular coordinate files remain available in `results/structures/`.

The visual reference informed the paired RNA/protein layout and blue/red parent colors. Its screenshot was not reused as an experimental finding. Slide 4 pairs sequence-backed exon architecture with the actual low-confidence Boltz2 model. Slide 11 separates the experimental parent GSDMD structure from the predicted chimera. No undocumented UTR or ORF claims are introduced for the other RNA examples.

## Build

Use a separate environment; the analytical project's root dependencies are unchanged:

```bash
uv venv /tmp/chrna-slide-venv
uv pip install --python /tmp/chrna-slide-venv/bin/python -r scripts/presentation/requirements.txt
/tmp/chrna-slide-venv/bin/python scripts/presentation/build_gallery.py
```

CairoSVG also needs the system Cairo shared library (commonly `libcairo2`) and DejaVu Sans fonts. The authoring environment used Python 3.12, python-pptx 1.0.2, Pillow 12.3.0, CairoSVG 2.9.1, and pypdf 6.19.0. Frozen-result assertions stop the build if major narrative counts no longer match their source artifacts.

Outputs:

- `results/presentation/chRNA_gallery.pptx`: editable deck with source/method/caveat speaker notes on every slide.
- `results/presentation/gallery/01_workflow.svg` through `12_next_experiment.svg`, with corresponding PNG and one-page PDF files.
- `results/presentation/chRNA_gallery_source_render.pdf`: shared-source reference render, explicitly distinct from the actual PowerPoint rendering.
- `results/presentation/gallery/figure_manifest.json`: figure paths, methods, sources, limitations, editable-element counts and input hashes.

## Render the actual PowerPoint

With LibreOffice and Poppler's `pdftoppm` available:

```bash
/tmp/chrna-slide-venv/bin/python scripts/presentation/render_gallery.py
```

The renderer supports `CHRNA_LIBREOFFICE_BIN`, `CHRNA_PDFTOPPM_BIN`, and `CHRNA_RENDER_LIBRARY_PATH` for isolated installations. In the build session, LibreOffice 24.2.7 and its dependencies were downloaded/extracted under `/tmp/chrna-lo`, its package registry initialized there, and no system packages or root analytical dependencies were modified.

Actual rendered outputs are `chRNA_gallery.pdf`, `gallery/pptx_render/slide-01.png` through `slide-12.png`, and `gallery_contact_sheet.png`. The contact sheet is overwritten with the actual PowerPoint render after successful rendering. `gallery/render_validation.json` records the actual PPTX/PDF hashes and checks slide/page/image counts, editable elements, speaker notes and key numeric text.

Every figure's interpretation and source details are in the root-owned `results/presentation/FIGURE_GUIDE.md`. The candidate exon inputs and independent ORF verification are generated by separate root-owned scripts; this builder consumes their frozen JSON outputs.
