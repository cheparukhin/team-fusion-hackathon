# Scientific inputs retained from presentation preparation

The [current presentation](https://docs.google.com/presentation/d/1qZ2owRuz6j3A48Y_XcheWADuoPh6HYkmn2NCLqFDybk/edit) is maintained in Google Slides and follows the [FINAL-tab scope](../../docs/submission/README.md). Superseded slide exports are retained only in the earlier published release.

Two standard-library scientific preparation scripts remain:

- `build_candidate_examples.py` reconstructs source-backed candidate examples.
- `verify_reference_orf.py` independently checks the reconstructed reference ORF.

Their frozen outputs remain in [results/presentation](../../results/presentation/README.md) because the structure-campaign report consumes them. They do not constitute another current presentation. Rebuilding them requires the source inputs referenced by those scripts and changes the corresponding local outputs; it is not necessary to view the final deck or cached results.
