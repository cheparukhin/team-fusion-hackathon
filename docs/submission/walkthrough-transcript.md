# Recorded evidence walkthrough

Synthetic narration using macOS Daniel voice. Three native slide snapshots; not a recording of browser interaction or a live agent call.

## Slide 1

This is a recorded evidence walkthrough for Team Fusion, using synthetic narration. We built an assistant to help scientists decide which chimeric R N A junction to test next. A chimeric R N A joins parts of two genes. A high score for a gene pair does not tell a scientist which exact junction to target. Our workflow brings together published reads, designed probes, independent short-read evidence and primary-paper passages. The contribution demonstrated here is a traceable review decision. We are not claiming a new biological discovery or measured time savings.

## Slide 3

This is the decision that matters. The candidate shown has six distinct published long-read identifiers and a high, uncalibrated pair-level score. Yet the nearest published read endpoint differs from the sequence-mapped probe endpoint by nine hundred and twenty-four nucleotides. A separate calculation from the original source tables and reference transcripts reproduced that descriptive discrepancy. It does not prove a bad probe or a false R N A. It identifies the next uncertainty: reconcile the original read alignment and coordinate convention before choosing a junction-specific assay. The bounded Parabricks sample found no matching probe-junction reads; that does not prove absence. We also tested whether Hi-C improved ranking, and found no established gain. The useful result is an inspectable path from conflicting evidence to a concrete next check. Source records, exact replay, limitations and the proposed decision are included in the repository. Prospective utility testing and independent scientist review remain to be done.
